# Sabari Bala M R - Developer Portfolio

A clean, modern, and fully responsive developer portfolio built with React, Vite, and Tailwind CSS.

## Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React with custom brand SVGs

## Features

- Fully responsive, SaaS-style layout
- Premium monochromatic design with an emerald green accent
- Accessible keyboard navigation and visible focus states
- Config-driven project and skills data in `src/config/portfolio.js`
- Static-site architecture suitable for deployment

## Local Development

### Prerequisites

Install Node.js and npm before starting.

### Clone the repository

```bash
git clone https://github.com/Sabari-bala/portfolio.git
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The generated production files will be available in the `dist/` directory.

## Deployment

This Vite application can be deployed to a static hosting platform such as Vercel.

- **Build command:** `npm run build`
- **Output directory:** `dist`
